    3️⃣ Procesadores de texto

    En cualquier empresa, independientemente de su tamaño o actividad, es necesario crear documentos: informes, contratos, presupuestos, manuales, cartas, instrucciones, actas de reuniones y documentación técnica.

    En una empresa de informática, por ejemplo, un técnico puede necesitar elaborar un informe después de reparar un ordenador, redactar un manual para que un usuario aprenda a utilizar una aplicación o documentar los pasos necesarios para instalar un servidor.

    Para realizar estas tareas se utilizan los procesadores de texto, aplicaciones informáticas diseñadas para crear, editar, dar formato, guardar, revisar e imprimir documentos escritos.

    Un procesador de textos permite separar el contenido del documento de su presentación. Esto significa que podemos escribir la información y, posteriormente, decidir cómo queremos que aparezca: qué tipo de letra utilizaremos, cómo distribuiremos los párrafos, dónde colocaremos las imágenes o cómo organizaremos los títulos.

    Además, los procesadores modernos incorporan funciones para trabajar con tablas, imágenes, índices automáticos, plantillas, comentarios, revisión ortográfica y exportación a PDF.

    1.1. Procesador de textos frente a editor de texto

    Aunque ambos permiten escribir, no son exactamente lo mismo.

    Característica Editor de texto Procesador de textos
    Finalidad principal Editar texto sencillo o código Crear documentos estructurados
    Formato de caracteres Generalmente limitado a la visualización del editor Fuentes, tamaños, colores y efectos
    Formato de párrafos Limitado o inexistente Alineación, sangrías e interlineado
    Imágenes y tablas Normalmente no se gestionan como elementos del documento Se pueden insertar y configurar
    Diseño de página No suele incluirlo Márgenes, orientación, encabezados y pies
    Uso habitual Configuración, programación y archivos de texto Informes, cartas, manuales y trabajos
    Ejemplos Bloc de notas, nano, Vim LibreOffice Writer, Microsoft Word

    Un archivo de código fuente, como programa.js, suele editarse con un editor de texto o un entorno de desarrollo. Un informe de reparación, en cambio, se crea habitualmente con un procesador de textos.

    Importante: un archivo de texto plano no almacena las características de presentación de un documento enriquecido. En un archivo .txt no se conserva, por ejemplo, que un título tenga 20 puntos, esté centrado y aparezca en negrita.

    1.2. Principales funciones de un procesador de textos

    Las funciones más importantes son:

    • Edición: introducir, borrar, copiar, cortar, pegar y mover texto.
    • Formato: modificar la apariencia de caracteres, párrafos y páginas.
    • Estructuración: organizar el contenido mediante títulos, subtítulos y listas.
    • Inserción de elementos: añadir imágenes, tablas, enlaces y otros objetos.
    • Revisión: detectar errores ortográficos, buscar palabras y sustituir expresiones.
    • Automatización: generar índices, utilizar plantillas y mantener estilos coherentes.
    • Almacenamiento: guardar documentos en formatos editables.
    • Intercambio: exportar documentos a PDF o utilizar formatos compatibles con otras aplicaciones.
    • Impresión: preparar el documento para su reproducción en papel.

    1.3. Aplicaciones más utilizadas

    Entre los procesadores de textos más conocidos encontramos:

    • LibreOffice Writer: aplicación gratuita y de código abierto, disponible para distintos sistemas operativos.
    • Microsoft Word: procesador de textos de Microsoft, disponible en versiones de escritorio y web.
    • Google Docs: aplicación web que facilita la edición colaborativa.
    • ONLYOFFICE Docs: suite ofimática con funciones de edición y colaboración.
    • Apple Pages: aplicación de Apple para crear documentos.

    Aunque las interfaces son diferentes, los conceptos fundamentales —estilos, párrafos, márgenes, tablas, imágenes y formatos— son muy similares.

    1.4. ¿Qué es LibreOffice Writer?

    Writer es el procesador de textos incluido en LibreOffice. Permite crear documentos profesionales sin necesidad de adquirir una licencia comercial.

    Su formato nativo es ODT, basado en el estándar OpenDocument. También puede abrir y guardar documentos de otros formatos, como DOCX, además de exportar a PDF.

    Sus principales características son:

    • Edición de documentos de texto.
    • Gestión de estilos y plantillas.
    • Creación de tablas e inserción de imágenes.
    • Generación de índices automáticos.
    • Revisión ortográfica.
    • Exportación a PDF.
    • Compatibilidad con diferentes sistemas operativos.

    En este tema utilizaremos Writer como herramienta principal, aunque las técnicas aprendidas también servirán para trabajar con otros procesadores.

    2. Conceptos fundamentales de un documento

    Antes de empezar a trabajar con Writer, conviene distinguir los elementos que forman un documento.

    2.1. Carácter

    Un carácter es una unidad individual de texto: una letra, un número, un signo de puntuación o un espacio.

    Por ejemplo, en la palabra Servidor hay ocho caracteres.

    Los caracteres pueden tener diferentes propiedades de formato:

    • Tipo de fuente.
    • Tamaño.
    • Color.
    • Negrita.
    • Cursiva.
    • Subrayado.
    • Otros efectos tipográficos.

    2.2. Palabra

    Una palabra es una secuencia de caracteres que, normalmente, se encuentra delimitada por espacios o signos de puntuación.

    Los procesadores de textos pueden utilizar las palabras como unidades para seleccionar, buscar, reemplazar o corregir contenido.

    2.3. Párrafo

    Un párrafo es una unidad de texto que termina cuando se introduce una marca de párrafo, normalmente pulsando Intro.

    Un párrafo puede contener una sola línea o muchas líneas. Su longitud no determina dónde termina: lo hace la marca de párrafo.

    Cada párrafo puede tener sus propias propiedades:

    • Alineación.
    • Sangrías.
    • Espaciado anterior y posterior.
    • Interlineado.
    • Bordes y fondo.
    • Tabulaciones.

    Error habitual: pulsar Intro al final de cada línea para conseguir que el texto tenga una anchura determinada. Esto crea muchos párrafos innecesarios y dificulta los cambios de formato.

    Lo correcto es escribir de forma continua y dejar que el procesador adapte las líneas automáticamente al ancho disponible.

    2.4. Página

    La página es el espacio físico o virtual sobre el que se distribuye el documento.

    Entre sus propiedades encontramos:

    • Tamaño del papel.
    • Orientación vertical u horizontal.
    • Márgenes.
    • Encabezado y pie de página.
    • Numeración.
    • Distribución del contenido.

    Una página puede contener varios párrafos, imágenes, tablas y otros elementos.

    2.5. Estilo

    Un estilo es un conjunto de propiedades de formato guardadas bajo un nombre.

    Por ejemplo, podemos definir un estilo llamado Título 1 con las siguientes características:

    • Fuente de 18 puntos.
    • Negrita.
    • Color azul oscuro.
    • Espaciado anterior de 12 puntos.
    • Espaciado posterior de 6 puntos.

    Después podemos aplicar ese estilo a todos los títulos principales del documento.

    La principal ventaja es que, si queremos cambiar el aspecto de los títulos, podemos modificar el estilo una sola vez en lugar de editar cada título individualmente.

    2.6. Diferencia entre contenido y presentación

    Imaginemos que redactamos un manual con estos apartados:

    1. Introducción.
    2. Instalación.
    3. Configuración.
    4. Resolución de problemas.

    Podríamos escribir cada apartado y aumentar manualmente el tamaño de la fuente para distinguir los títulos. Sin embargo, sería más adecuado asignarles estilos de título.

    En el primer caso, el programa conoce principalmente la apariencia del texto. En el segundo, también conoce su función estructural.

    Esta diferencia es importante porque permite generar índices automáticos, reorganizar el documento y mejorar su accesibilidad.

    3. La interfaz de LibreOffice Writer

    Al abrir Writer aparece una ventana con distintas áreas de trabajo.

    La disposición exacta puede variar según la versión instalada, el sistema operativo y la configuración de la interfaz.

    3.1. Elementos principales

    Barra de título: muestra el nombre del documento y la aplicación.

    Barra de menús: contiene las categorías principales de comandos, como Archivo, Editar, Ver, Insertar, Formato, Estilos, Tabla, Herramientas y Ayuda.

    Barras de herramientas: proporcionan accesos directos a operaciones frecuentes, como guardar, deshacer, imprimir o cambiar el formato.

    Área de edición: es la zona central donde se escribe y modifica el documento.

    Reglas: permiten visualizar y ajustar márgenes, sangrías y tabulaciones.

    Barras de desplazamiento: permiten moverse por el documento.

    Barra de estado: muestra información como el número de página, el recuento de palabras, el idioma o el nivel de zoom.

    Panel lateral: permite acceder a propiedades, estilos, galerías y otras herramientas.

    3.2. La barra de herramientas de formato

    Entre los controles más habituales encontramos:

    • Selector de fuente.
    • Tamaño de letra.
    • Negrita.
    • Cursiva.
    • Subrayado.
    • Color de fuente.
    • Color de resaltado.
    • Alineación izquierda, centrada, derecha y justificada.
    • Listas con viñetas y numeración.
    • Espaciado y otras opciones de formato.

    Estos controles son atajos a funciones que también se pueden encontrar en los menús.

    No es necesario memorizar la ubicación de todos los botones. Lo importante es entender qué operación realiza cada uno y saber localizarla.

    3.3. El cursor de texto y el puntero del ratón

    No deben confundirse.

    El cursor de texto indica dónde aparecerán los caracteres que escribamos. Normalmente se representa mediante una línea vertical parpadeante.

    El puntero del ratón es el indicador que desplazamos para seleccionar texto, pulsar botones o acceder a los menús.

    Para colocar el cursor en una posición determinada, basta con hacer clic en esa zona del documento.

    3.4. Mostrar las marcas de formato

    Writer permite visualizar las marcas que normalmente no se imprimen:

    • Espacios.
    • Marcas de párrafo.
    • Tabulaciones.
    • Saltos de línea.
    • Otros caracteres de control.

    Esta opción es especialmente útil para detectar problemas de maquetación.

    Por ejemplo, si un documento tiene espacios excesivos entre palabras o páginas en blanco inesperadas, mostrar las marcas de formato puede ayudar a identificar su causa.

    La opción suele encontrarse en Ver → Marcas de formato, aunque el nombre o el acceso directo pueden variar según la versión.

    3.5. Atajos de teclado fundamentales

    Los siguientes atajos son habituales en Writer para Windows y GNU/Linux:

    Acción Atajo habitual
    Nuevo documento Ctrl + N
    Abrir documento Ctrl + O
    Guardar Ctrl + S
    Imprimir Ctrl + P
    Deshacer Ctrl + Z
    Rehacer Ctrl + Y
    Cortar Ctrl + X
    Copiar Ctrl + C
    Pegar Ctrl + V
    Seleccionar todo Ctrl + A
    Buscar Ctrl + F
    Negrita Ctrl + B
    Cursiva Ctrl + I
    Subrayado Ctrl + U
    Insertar salto de página manual Ctrl + Intro

    Los atajos pueden variar en función del sistema, la configuración o la versión. En macOS suelen utilizarse combinaciones con la tecla Comando en lugar de Ctrl.

    4. Crear, abrir y guardar documentos

    La gestión correcta de los archivos es una parte esencial del trabajo ofimático.

    4.1. Crear un documento nuevo

    Para crear un documento nuevo:

    1. Abre LibreOffice Writer.
    2. Selecciona Archivo → Nuevo → Documento de texto, si no aparece ya un documento vacío.
    3. Introduce el contenido.
    4. Guarda el documento con un nombre adecuado.

    También se puede utilizar el atajo Ctrl + N.

    4.2. Abrir un documento existente

    Para abrir un documento guardado:

    1. Selecciona Archivo → Abrir.
    2. Busca la carpeta donde se encuentra el archivo.
    3. Selecciónalo.
    4. Pulsa Abrir.

    El programa intentará interpretar el contenido y el formato del archivo.

    Si el documento utiliza características que no están disponibles o no son totalmente compatibles, puede que su apariencia cambie.

    4.3. Guardar por primera vez

    Cuando guardamos un documento nuevo, Writer necesita conocer:

    • El nombre del archivo.
    • La carpeta de destino.
    • El formato de archivo.

    Por ejemplo:

    informe-incidencia-001.odt

    Es preferible utilizar nombres descriptivos, sin depender de nombres genéricos como Documento1 o Nuevo documento.

    4.4. Guardar los cambios

    Una vez que el documento tiene nombre y ubicación, Ctrl + S permite guardar los cambios.

    Es recomendable guardar periódicamente, especialmente cuando se trabaja con documentos largos.

    No conviene confiar exclusivamente en la recuperación automática: esta función puede ayudar, pero no sustituye a guardar el trabajo.

    4.5. Guardar como

    La opción Guardar como permite guardar una copia con otro nombre, en otra carpeta o en otro formato.

    Por ejemplo, podemos mantener el documento original y crear una versión destinada a un cliente:

    • informe-interno.odt
    • informe-cliente.pdf

    También puede utilizarse para crear una versión compatible con una aplicación que requiera DOCX.

    Hay que distinguir entre guardar una copia y sobrescribir el archivo original. Antes de confirmar, debemos comprobar el nombre y la ubicación.

    4.6. Elegir una estructura de carpetas

    En una empresa es recomendable organizar los documentos por proyecto, cliente o tipo de actividad.

    Por ejemplo:

    Documentacion/
├── Clientes/
│   ├── Cliente_A/
│   │   ├── Informes/
│   │   ├── Presupuestos/
│   │   └── Manuales/
│   └── Cliente_B/
├── Plantillas/
└── Procedimientos/

    Una estructura clara facilita encontrar documentos y evita que se mezclen versiones.

    4.7. Copias de seguridad y versiones

    En trabajos importantes conviene mantener copias de seguridad y un sistema de versiones.

    Por ejemplo:

    informe-red-v01.odt
informe-red-v02.odt
informe-red-final.odt

    Este sistema puede resultar útil, aunque acumular archivos con nombres como final-definitivo-2 acaba generando confusión.

    En proyectos colaborativos es preferible establecer una convención de nombres y utilizar un sistema de control de versiones documentales cuando proceda.

    4.8. Formatos de archivo

    Los formatos más relevantes son:

    Extensión Descripción Uso habitual
    ODT OpenDocument Text Formato editable nativo de Writer
    DOCX Documento de Microsoft Word Intercambio con usuarios de Word
    DOC Formato antiguo de Word Compatibilidad con documentos heredados
    RTF Rich Text Format Intercambio de texto con formato
    TXT Texto sin formato Texto plano, sin maquetación enriquecida
    PDF Portable Document Format Distribución e impresión

    Recomendación: conserva una copia editable en ODT o en el formato de trabajo acordado y genera un PDF cuando necesites distribuir una versión final cuya presentación deba mantenerse estable.

    5. Edición básica del texto

    Antes de aplicar formatos avanzados es necesario dominar las operaciones básicas de edición.

    5.1. Introducir texto

    Al escribir, Writer ajusta automáticamente el texto al ancho disponible.

    Cuando llegamos al final de una línea, el programa continúa en la siguiente sin necesidad de pulsar Intro.

    Intro se utiliza para comenzar un nuevo párrafo, no para cambiar de línea cada vez que el texto alcanza el margen.

    5.2. Seleccionar texto

    Para modificar una parte del documento, primero debemos seleccionarla.

    Podemos seleccionar:

    • Un carácter.
    • Una palabra.
    • Una frase.
    • Un párrafo.
    • Todo el documento.

    La selección se puede realizar arrastrando el ratón o utilizando el teclado.

    Por ejemplo, con Ctrl + A se selecciona el contenido completo en las configuraciones habituales de Writer.

    5.3. Copiar, cortar y pegar

    Copiar crea una copia del contenido seleccionado en el portapapeles.

    Cortar elimina el contenido de su posición original y lo coloca en el portapapeles.

    Pegar inserta el contenido del portapapeles en la posición actual del cursor.

    Ejemplo:

    1. Escribe Configuración del equipo.
    2. Selecciona la frase.
    3. Cópiala.
    4. Sitúa el cursor en otro párrafo.
    5. Pégala.

    El resultado será que la frase aparecerá en dos posiciones.

    5.4. Arrastrar y mover texto

    También se puede seleccionar texto y arrastrarlo a otra posición. Esta operación requiere cuidado porque podemos mover contenido accidentalmente.

    Para cambios importantes, cortar y pegar suele resultar más controlable.

    5.5. Deshacer y rehacer

    Deshacer permite revertir una operación reciente. Rehacer permite recuperar una operación que se había deshecho.

    Son herramientas esenciales para experimentar con el formato sin tener que empezar de nuevo.

    Sin embargo, no debemos utilizarlas como sustituto de una estrategia de guardado y copias de seguridad.

    5.6. Buscar y reemplazar

    La búsqueda permite localizar una palabra o expresión.

    La función de reemplazo permite sustituir una expresión por otra en una o varias partes del documento.

    Ejemplo: en un manual antiguo aparece el nombre Servidor01, pero ahora el equipo se llama Servidor02.

    Podemos buscar Servidor01 y reemplazarlo por Servidor02.

    Antes de utilizar el reemplazo global, debemos revisar si todas las apariciones deben modificarse. Una misma palabra puede aparecer en contextos donde el cambio no sea adecuado.

    • ©
    • €
    • ±
    • →
    • ≤
    • ≥

    Para documentación técnica, conviene comprobar que la fuente elegida contiene los símbolos necesarios.

    6. Formato de caracteres

    El formato de caracteres modifica la apariencia de las letras, números y símbolos.

    6.1. Tipo de fuente

    La fuente determina el diseño visual de los caracteres.

    Algunos ejemplos habituales son:

    • Arial.
    • Liberation Sans.
    • Calibri.
    • Times New Roman.
    • Liberation Serif.
    • DejaVu Sans.
    • Noto Sans.

    La elección depende del tipo de documento y de las fuentes disponibles en el sistema.

    Para documentos técnicos suele ser conveniente utilizar fuentes legibles y evitar mezclar demasiadas tipografías.

    6.2. Tamaño de fuente

    El tamaño suele expresarse en puntos tipográficos (pt).

    Un punto equivale a 1/72 de pulgada.

    Como referencia orientativa:

    Elemento Tamaño habitual
    Texto principal 10–12 pt
    Título principal 20–28 pt
    Título de apartado 14–18 pt
    Nota secundaria 9–10 pt

    No son valores obligatorios. Deben adaptarse al contenido, al público y a los requisitos del documento.

    6.3. Negrita, cursiva y subrayado

    Negrita: destaca palabras o fragmentos importantes.

    Cursiva: se utiliza para títulos de obras, términos extranjeros en determinados contextos o énfasis moderado.

    Subrayado: puede emplearse para destacar información, aunque conviene reservarlo para casos concretos porque puede confundirse con un enlace.

    No es recomendable aplicar simultáneamente todos los efectos a grandes bloques de texto.

    6.4. Color de fuente y resaltado

    El color puede ayudar a distinguir elementos, pero debe utilizarse con moderación.

    En documentación profesional es conveniente mantener una paleta reducida y comprobar que existe suficiente contraste entre el texto y el fondo.

    No se debe transmitir información exclusivamente mediante el color. Por ejemplo, un error no debería distinguirse únicamente porque aparezca en rojo: también debe estar identificado mediante texto o símbolos.

    6.5. Superíndice y subíndice

    El superíndice sitúa los caracteres por encima de la línea base. El subíndice los sitúa por debajo.

    Ejemplos:

    • m² para metros cuadrados.
    • CO₂ para dióxido de carbono.
    • x² para una potencia.

    Estas opciones son útiles en documentos científicos, matemáticos y técnicos.

    6.6. Aplicar formato correctamente

    Para cambiar el formato de una palabra:

    1. Selecciona la palabra.
    2. Elige la fuente o el tamaño deseado.
    3. Aplica los efectos necesarios.
    4. Comprueba el resultado.
    5. Guarda el documento.

    La selección previa es importante: si no hay texto seleccionado, algunos cambios pueden aplicarse al texto que se escriba a continuación o al elemento activo.

    6.7. Evitar el formato excesivo

    Un documento profesional debe facilitar la lectura.

    Es preferible utilizar dos o tres niveles tipográficos bien definidos que una combinación de muchas fuentes, colores, tamaños y efectos.

    Por ejemplo, un manual puede utilizar:

    • Una fuente para el texto principal.
    • Una fuente monoespaciada para comandos y fragmentos de código.
    • Un color de acento para títulos o advertencias.

    7. Formato de párrafos

    El formato de párrafo determina cómo se distribuye el texto dentro de los límites de la página.

    7.1. Alineación

    Writer permite utilizar cuatro alineaciones principales.

    Izquierda: el texto comienza en el margen izquierdo. Es la opción más habitual para textos generales.

    Centrada: el texto se distribuye respecto al centro de la línea. Se utiliza frecuentemente en títulos.

    Derecha: el texto termina alineado con el margen derecho. Puede utilizarse en fechas, firmas o determinados elementos.

    Justificada: el texto se ajusta a ambos márgenes mediante la distribución de los espacios entre palabras.

    La justificación puede ser apropiada para determinados documentos largos, aunque puede producir espacios irregulares cuando las líneas son cortas.

    7.2. Sangrías

    La sangría modifica la posición del párrafo respecto a los márgenes.

    Tipos habituales:

    • Izquierda: desplaza el párrafo respecto al margen izquierdo.
    • Derecha: limita el párrafo por el lado derecho.
    • Primera línea: desplaza únicamente la primera línea.
    • Francesa: desplaza las líneas posteriores a la primera.

    La sangría francesa resulta útil en bibliografías y listas de referencias.

    Las sangrías se pueden configurar desde las propiedades del párrafo o mediante los controles de la regla.

    7.3. Espaciado anterior y posterior

    Permite establecer el espacio que aparece antes y después de cada párrafo.

    Es preferible controlar el espacio mediante las propiedades del párrafo en lugar de insertar líneas vacías pulsando Intro repetidamente.

    Por ejemplo, un estilo de texto puede utilizar:

    • Espaciado anterior: 0 pt.
    • Espaciado posterior: 6 pt.

    Un título puede tener un espaciado anterior mayor para separarlo del contenido precedente.

    7.4. Interlineado

    El interlineado controla la distancia vertical entre líneas de un mismo párrafo.

    Entre las opciones habituales encontramos:

    • Sencillo.
    • 1,15 líneas.
    • 1,5 líneas.
    • Doble.
    • Proporcional o personalizado, según las opciones disponibles.

    Un interlineado demasiado reducido dificulta la lectura. Uno excesivo puede hacer que el documento resulte innecesariamente largo.

    7.5. Bordes y fondos de párrafo

    Se pueden aplicar bordes y fondos para destacar avisos, notas o bloques de información.

    Por ejemplo:

    Nota técnica: antes de actualizar el firmware de un equipo, comprueba la compatibilidad de la versión y realiza una copia de seguridad de la configuración cuando sea posible.

    En un documento real, este aviso podría aparecer dentro de un párrafo con fondo suave y un borde lateral.

    Es importante que el formato no sustituya a una estructura clara ni dificulte la lectura.

    7.6. Evitar líneas aisladas

    En documentos largos puede ocurrir que una línea de un párrafo quede sola al principio o al final de una página.

    Writer ofrece opciones de control de viudas y huérfanas, así como otras propiedades de flujo del texto. Su configuración exacta puede depender de la versión y del estilo utilizado.

    Estas opciones ayudan a mejorar la presentación de informes y manuales.

    8. Estilos y estructura del documento

    Los estilos son una de las herramientas más importantes de un procesador de textos. Permiten mantener una presentación coherente y automatizar tareas.

    8.1. ¿Qué es un estilo?

    Un estilo es una definición reutilizable de propiedades de formato.

    En lugar de aplicar manualmente una fuente, un tamaño, un color y unos espacios a cada título, podemos crear o modificar un estilo y aplicarlo donde corresponda.

    Los estilos permiten:

    • Mantener una apariencia uniforme.
    • Cambiar el formato global con facilidad.
    • Generar índices automáticos.
    • Navegar por documentos largos.
    • Mejorar la accesibilidad.
    • Facilitar el mantenimiento del documento.

    8.2. Tipos de estilos

    Writer dispone de distintos tipos de estilos, entre ellos:

    Tipo de estilo Función
    Estilos de párrafo Controlan el formato de párrafos completos
    Estilos de carácter Aplican formato a fragmentos de texto
    Estilos de página Definen propiedades de página
    Estilos de lista Controlan la apariencia de listas
    Estilos de marco Configuran determinados objetos y marcos

    Los estilos de párrafo son especialmente importantes para organizar títulos y texto principal.

    8.3. Título y subtítulos

    Writer incorpora estilos de encabezado, normalmente denominados Título 1, Título 2, Título 3 y sucesivos niveles.

    Se pueden utilizar de la siguiente manera:

    • Título 1: apartados principales.
    • Título 2: subapartados.
    • Título 3: subdivisiones de los subapartados.

    Ejemplo:

    1. Instalación del sistema
   1.1. Requisitos previos
   1.2. Preparación del equipo
        1.2.1. Copia de seguridad
        1.2.2. Comprobación del espacio
2. Configuración inicial
   2.1. Idioma
   2.2. Actualizaciones

    Los títulos no deben elegirse únicamente por su apariencia. Es importante que el nivel aplicado represente la jerarquía real del contenido.

    8.4. Aplicar un estilo

    Para aplicar un estilo de título:

    1. Selecciona el párrafo del título o coloca el cursor dentro de él.
    2. Abre el selector de estilos.
    3. Elige el estilo de título adecuado.
    4. Comprueba el resultado.

    No es necesario seleccionar todas las palabras del párrafo si se está aplicando un estilo de párrafo.

    8.5. Modificar un estilo

    Si todos los títulos principales deben tener un tamaño mayor, no es necesario modificarlos uno por uno.

    Podemos modificar el estilo correspondiente:

    1. Abre el panel de estilos.
    2. Localiza el estilo que deseas cambiar.
    3. Accede a su edición.
    4. Ajusta las propiedades.
    5. Aplica los cambios.

    Todos los párrafos que utilizan ese estilo podrán actualizar su presentación de acuerdo con la nueva definición.

    8.6. Índices automáticos

    Una de las grandes ventajas de utilizar estilos de título es que Writer puede generar un índice a partir de ellos.

    El procedimiento general es:

    1. Estructura el documento con los estilos de título.
    2. Sitúa el cursor donde quieras insertar el índice.
    3. Abre el menú de índices y tablas.
    4. Inserta un índice de contenido.
    5. Comprueba que aparecen los títulos correctos.
    6. Actualiza el índice cuando cambie el documento.

    El nombre exacto de las opciones puede variar según la versión.

    Si escribimos los títulos manualmente sin utilizar estilos estructurales, el índice automático puede no reconocerlos como esperamos.

    8.7. El panel del navegador

    El navegador de Writer permite desplazarse por títulos, tablas, imágenes y otros elementos del documento.

    Resulta especialmente útil cuando trabajamos con manuales largos.

    Una estructura correcta permite saltar directamente a un apartado sin tener que recorrer todas las páginas.

    10. Tabulaciones y alineación de datos

    Las tabulaciones permiten situar el texto en posiciones concretas dentro de una línea.

    Son útiles para organizar información que necesita una alineación consistente.

    10.1. Tipos de tabulaciones

    Entre los tipos habituales encontramos:

    • Izquierda: el texto comienza en la posición establecida.
    • Centrada: el texto se centra respecto a esa posición.
    • Derecha: el texto termina en la posición establecida.
    • Decimal: alinea valores numéricos por su separador decimal.

    Las tabulaciones se pueden configurar desde la regla o desde las propiedades del párrafo.

    10.2. Tabulaciones frente a espacios

    Supongamos que queremos crear una lista de equipos y precios:

    Equipo A       450 €
Equipo B       720 €
Equipo C      1250 €

    Si alineamos los precios mediante espacios, el resultado puede cambiar al modificar la fuente o el contenido.

    Una tabulación correctamente configurada proporciona una alineación más estable.

    Cuando necesitamos una estructura realmente tabular, con filas y columnas, es preferible utilizar una tabla.

    10.3. Líderes de tabulación

    Los líderes son caracteres que rellenan el espacio hasta la posición de tabulación.

    Por ejemplo:

    Introducción............................1
Instalación.............................4
Configuración...........................8

    Pueden resultar útiles para crear índices manuales sencillos, aunque para documentos extensos es mejor utilizar índices automáticos.

    11. Configuración de página

    La configuración de página determina el espacio disponible y la distribución general del documento.

    11.1. Tamaño del papel

    Entre los tamaños más comunes se encuentra A4, habitual en la documentación administrativa y académica española.

    También pueden utilizarse otros tamaños en función de las necesidades de impresión.

    11.2. Orientación

    Existen dos orientaciones principales:

    Vertical: la altura es mayor que la anchura. Es la opción habitual para informes y documentos de texto.

    Horizontal: la anchura es mayor que la altura. Puede resultar adecuada para tablas amplias, diagramas o documentos con elementos apaisados.

    La orientación debe elegirse según el contenido, no únicamente para intentar que una tabla quepa en una página.

    11.3. Márgenes

    Los márgenes son los espacios entre el contenido y los bordes de la página.

    Se utilizan para mejorar la legibilidad, evitar que el contenido quede demasiado cerca del borde y permitir la encuadernación cuando sea necesaria.

    En documentos convencionales pueden utilizarse márgenes de aproximadamente 2 a 2,5 cm, aunque deben respetarse los requisitos específicos de cada trabajo.

    11.4. Saltos de página

    Un salto de página manual permite comenzar un contenido en la página siguiente.

    Por ejemplo, puede ser útil para que cada capítulo de un manual comience en una página nueva.

    No es recomendable pulsar Intro repetidamente para desplazar el contenido a otra página: si el documento cambia, esos saltos artificiales pueden provocar páginas vacías y problemas de distribución.

    Utiliza el salto de página correspondiente o las opciones de flujo del estilo cuando el documento lo requiera.

    11.5. Cambiar la configuración

    En Writer, las propiedades de página se gestionan mediante los estilos de página y las opciones correspondientes del menú Formato.

    Según la versión, los nombres de los menús pueden variar.

    Antes de modificar la configuración de un documento existente, conviene comprobar si el cambio debe afectar a todo el documento o solamente a determinadas páginas.

    12.3. Numeración automática

    La numeración debe insertarse mediante el campo correspondiente, no escribiendo manualmente el número de cada página.

    Si escribimos el número 1 en el pie de página y lo copiamos al resto de páginas, todas mostrarán el mismo valor.

    Con la numeración automática, Writer calcula el número que corresponde a cada página.

    12.4. Número de página y total de páginas

    Un documento puede mostrar información como:

    Página 3 de 12

    Para conseguirlo se utilizan campos automáticos para el número de página actual y el total de páginas.

    12.5. Primera página diferente

    En informes, portadas y trabajos académicos puede ser conveniente que la primera página no tenga el mismo encabezado o pie que el resto.

    Los estilos de página permiten configurar estas diferencias.

    13. Tablas

    Las tablas permiten organizar información en filas y columnas.

    Son especialmente útiles para presentar inventarios, presupuestos, resultados de pruebas, comparativas y partes de incidencias.

    13.1. Filas, columnas y celdas

    Una tabla está formada por:

    • Filas: agrupaciones horizontales.
    • Columnas: agrupaciones verticales.
    • Celdas: intersecciones de filas y columnas.

    Ejemplo de inventario:

    Código Equipo Estado
    EQ-001 Ordenador de administración Correcto
    EQ-002 Portátil de soporte En revisión
    EQ-003 Impresora de red Correcto

    13.2. Insertar una tabla

    El procedimiento general es:

    1. Sitúa el cursor en la posición deseada.
    2. Selecciona la opción de insertar tabla.
    3. Define el número de filas y columnas.
    4. Introduce los datos.
    5. Ajusta el ancho de las columnas.
    6. Aplica un formato legible.

    13.3. Modificar la estructura

    Las herramientas de tabla permiten:

    • Añadir o eliminar filas.
    • Añadir o eliminar columnas.
    • Combinar celdas.
    • Dividir celdas.
    • Ajustar anchuras y alturas.
    • Alinear el contenido.
    • Aplicar bordes y fondos.

    Combinar celdas puede resultar útil para crear un encabezado general, pero debe hacerse de forma moderada para no dificultar la comprensión de la tabla.

    13.4. Formato de tablas

    Para mejorar la legibilidad:

    • Utiliza encabezados claros.
    • Mantén un contraste suficiente.
    • Evita demasiados colores.
    • Alinea los números de forma coherente.
    • Ajusta las anchuras según el contenido.
    • No reduzcas excesivamente el tamaño de letra.
    • Evita dividir información relacionada de manera confusa entre páginas.

    Cuando una tabla ocupa varias páginas, conviene configurar la repetición de las filas de encabezado si la herramienta y el diseño lo permiten.

    13.5. Tablas frente a espacios

    Nunca es recomendable construir una tabla utilizando espacios para simular columnas.

    El resultado puede cambiar con las fuentes, el tamaño de ventana o la impresión.

    Cuando los datos tienen una estructura de filas y columnas, debe utilizarse una tabla real.

    Conviene utilizar imágenes con una resolución adecuada y evitar ampliarlas excesivamente, ya que pueden perder calidad.

    14.2. Ajuste de texto

    Las opciones de ajuste determinan cómo se distribuye el texto alrededor de una imagen.

    Según el tipo de objeto y las opciones disponibles, puede elegirse entre diferentes modos, como mantener la imagen en línea con el texto o permitir que el texto la rodee.

    Para manuales sencillos, mantener ciertas imágenes en línea con el texto puede facilitar el control de su posición.

    14.3. Anclaje

    El anclaje determina cómo se relaciona la imagen con el documento.

    Por ejemplo, puede estar vinculada a un carácter, un párrafo o una página, según las opciones disponibles.

    Si una imagen se desplaza inesperadamente al editar el documento, conviene revisar su anclaje y su ajuste de texto.

    14.4. Redimensionar sin deformar

    Al cambiar el tamaño de una imagen, es importante conservar la proporción entre anchura y altura.

    De lo contrario, las fotografías pueden aparecer estiradas o comprimidas.

    También debemos tener en cuenta que cambiar el tamaño visual de una imagen no siempre reduce el espacio que ocupa el archivo original.

    14.5. Leyendas y referencias

    En documentación técnica es recomendable identificar las imágenes.

    Ejemplo:

    Figura 1. Vista posterior de un equipo informático con sus principales conexiones.

    Las leyendas pueden ayudar a localizar imágenes y, en documentos extensos, pueden utilizarse para generar índices de ilustraciones si se configura correctamente el documento.

    14.6. Derechos de uso y privacidad

    No todas las imágenes disponibles en Internet pueden utilizarse libremente.

    Cuando se incorporen imágenes a documentos que vayan a distribuirse, debemos respetar las licencias y condiciones de uso.

    También hay que evitar incluir en las capturas de pantalla contraseñas, datos personales, direcciones privadas o información confidencial.

    Actividad 10. Manual ilustrado

    Elabora una guía de conexión de periféricos que incluya:

    • Un título.
    • Una introducción.
    • Tres imágenes o capturas de pantalla.
    • Una leyenda para cada imagen.
    • Instrucciones numeradas.
    • Un apartado de errores frecuentes.

    15. Revisión ortográfica y lingüística

    Un documento técnicamente correcto también debe estar bien redactado.

    Los errores ortográficos, las frases ambiguas y la falta de coherencia pueden dificultar la comprensión de las instrucciones.

    15.1. Corrector ortográfico

    Writer incorpora herramientas para revisar la ortografía del documento.

    La revisión depende del idioma configurado y de los diccionarios disponibles.

    Si un documento en español se revisa con un diccionario de otro idioma, pueden aparecer numerosos avisos incorrectos.

    Por eso, antes de revisar, conviene comprobar el idioma asignado al texto.

    15.2. Diccionarios y términos técnicos

    Los documentos informáticos contienen términos que no siempre aparecen en los diccionarios generales:

    • Router.
    • Firmware.
    • Ethernet.
    • Firewall.
    • Servidor.
    • Script.

    El corrector puede marcarlos como desconocidos aunque sean adecuados en su contexto.

    No debemos aceptar automáticamente todas las sugerencias: es necesario comprobar si la corrección propuesta conserva el significado técnico.

    15.3. Buscar y reemplazar

    Esta función también resulta útil para unificar términos.

    Por ejemplo, un documento puede utilizar indistintamente PC, ordenador y equipo.

    Según el contexto, podemos decidir una denominación preferente y revisar el documento para mantener la coherencia.

    No siempre es conveniente reemplazar todas las apariciones: una palabra puede tener significados distintos en diferentes frases.

    15.4. Comentarios y control de cambios

    En trabajos colaborativos pueden utilizarse comentarios para proponer correcciones sin modificar directamente el contenido.

    El control de cambios permite registrar modificaciones y revisarlas antes de aceptarlas o rechazarlas.

    Estas funciones son útiles cuando un documento debe ser revisado por un responsable antes de su publicación.

    15.5. Redacción profesional

    Un buen documento técnico debe:

    • Utilizar frases claras.
    • Mantener una terminología coherente.
    • Evitar expresiones ambiguas.
    • Separar instrucciones diferentes.
    • Presentar los pasos en un orden lógico.
    • Revisar la puntuación.
    • Evitar errores de formato y numeración.

    Actividad 11. Revisión de un documento

    Redacta un texto técnico de aproximadamente una página e introduce deliberadamente varios errores ortográficos y de coherencia terminológica.

    Después:

    1. Configura correctamente el idioma.
    2. Ejecuta la revisión ortográfica.
    3. Revisa las sugerencias.
    4. Busca términos repetidos.
    5. Unifica la terminología.
    6. Guarda la versión corregida.

    16. Plantillas y automatización

    Las plantillas permiten reutilizar una estructura documental sin tener que empezar desde cero.

    16.1. ¿Qué es una plantilla?

    Una plantilla es un documento preparado para utilizarse como base de otros documentos.

    Puede incluir:

    • Logotipo.
    • Estilos.
    • Encabezados y pies.
    • Márgenes.
    • Tablas predefinidas.
    • Campos de identificación.
    • Secciones habituales.

    Por ejemplo, una empresa de mantenimiento informático puede utilizar una plantilla para todos sus informes de intervención.

    16.2. Ventajas de las plantillas

    • Reducen el tiempo necesario para crear documentos.
    • Mantienen una imagen corporativa coherente.
    • Disminuyen los errores de formato.
    • Facilitan que distintas personas trabajen con la misma estructura.
    • Permiten estandarizar la documentación.

    16.3. Ejemplo de plantilla de incidencia

    INFORME DE INCIDENCIA TÉCNICA

Código de incidencia:
Fecha:
Técnico responsable:
Departamento:

1. Descripción del problema

2. Comprobaciones realizadas

3. Diagnóstico

4. Solución aplicada

5. Resultado de las pruebas

6. Observaciones

Estado final:

    Esta estructura puede convertirse en una plantilla reutilizable.

    16.4. Campos automáticos

    Writer dispone de campos que pueden mostrar información como la fecha, el número de página u otros datos del documento.

    Los campos automáticos ayudan a evitar errores derivados de mantener información manualmente.

    Por ejemplo, si el documento incluye el número de página, no debemos escribirlo a mano en cada página.

    16.5. Generación de índices

    Cuando se utilizan correctamente los estilos, los índices se pueden generar y actualizar automáticamente.

    Esta automatización resulta especialmente útil en manuales y documentación extensa.

    Actividad 12. Crear una plantilla

    Diseña una plantilla de informe de mantenimiento informático.

    Debe incluir:

    • Título y datos identificativos.
    • Estilos de encabezado.
    • Tabla para identificar el equipo.
    • Apartados para diagnóstico y solución.
    • Encabezado o pie de página.
    • Campos automáticos cuando proceda.

    Guárdala en el formato de plantilla de Writer y comprueba que puedes crear un nuevo documento a partir de ella.

    17. Exportación a PDF y compatibilidad

    Una vez finalizado un documento, puede ser necesario compartirlo con otras personas.

    El formato elegido influye en la posibilidad de editarlo, conservar su apariencia y abrirlo en otras aplicaciones.

    17.1. ODT

    Es el formato nativo de documentos de texto de Writer.

    Sus principales ventajas son:

    • Conserva la estructura editable.
    • Permite modificar el documento.
    • Facilita la utilización de estilos.
    • Está basado en el estándar OpenDocument.

    Es una buena opción para conservar el archivo de trabajo cuando se utiliza LibreOffice.

    17.2. DOCX

    Es un formato habitual de Microsoft Word.

    Writer puede trabajar con documentos DOCX, pero algunas características complejas pueden interpretarse de forma diferente entre aplicaciones.

    Después de guardar un documento en DOCX, es recomendable volver a abrirlo y revisar su presentación, especialmente si contiene tablas complejas, estilos personalizados, imágenes o saltos de página.

    17.3. PDF

    PDF se utiliza ampliamente para distribuir documentos cuya apariencia debe mantenerse estable.

    Sus ventajas incluyen:

    • Conservación de la maquetación.
    • Facilidad de visualización.
    • Adecuación para impresión.
    • Amplia compatibilidad.
    • Posibilidad de incorporar enlaces y otras funciones.

    Sin embargo, un PDF no debe considerarse automáticamente un documento imposible de modificar. Existen herramientas que permiten editar determinados contenidos y algunos PDF contienen formularios u otros elementos interactivos.

    17.4. Exportar a PDF

    En Writer, el procedimiento habitual es:

    1. Guarda el documento editable.
    2. Selecciona la opción de exportar a PDF.
    3. Revisa las opciones disponibles.
    4. Exporta el archivo.
    5. Abre el PDF generado.
    6. Comprueba la presentación y los enlaces.

    No basta con exportar: hay que revisar el resultado.

    17.5. Compatibilidad y fuentes

    Un documento puede verse diferente al abrirse en otro ordenador debido a:

    • Fuentes que no están instaladas.
    • Diferencias entre aplicaciones.
    • Sustitución de tipografías.
    • Diferencias en la interpretación de tablas o imágenes.
    • Configuración de página.
    • Cambios en el contenido.

    Para reducir estos problemas, conviene utilizar fuentes comunes, mantener una estructura clara y comprobar los archivos exportados.

    17.6. ¿Qué formato debemos entregar?

    Situación Formato recomendado
    Seguir editando en Writer ODT
    Trabajar con usuarios de Word DOCX, comprobando la compatibilidad
    Entregar un informe final PDF
    Compartir texto sin formato TXT
    Reutilizar una estructura documental Plantilla de Writer

    En una entrega profesional puede ser conveniente proporcionar tanto el documento editable como el PDF final.

    18. Accesibilidad y buenas prácticas

    La documentación no debe diseñarse únicamente para que resulte atractiva. También debe poder leerse, comprenderse y utilizarse correctamente.

    18.1. Estructura semántica

    Utilizar estilos de título permite que las herramientas de navegación reconozcan la jerarquía del documento.

    Esto ayuda a personas que utilizan tecnologías de asistencia y también facilita la navegación en documentos largos.

    18.2. Contraste y legibilidad

    El texto debe distinguirse claramente del fondo.

    Conviene evitar:

    • Texto claro sobre fondo claro.
    • Texto oscuro sobre fondo oscuro.
    • Fuentes excesivamente pequeñas.
    • Párrafos demasiado densos.
    • Combinaciones de colores difíciles de distinguir.

    18.3. Imágenes informativas

    Cuando una imagen transmite información necesaria para comprender el documento, es conveniente proporcionar un texto alternativo adecuado.

    Por ejemplo, una captura de pantalla de una configuración de red debería describirse indicando qué información relevante contiene.

    No es suficiente escribir «imagen» como descripción.

    18.4. Tablas accesibles

    Las tablas deben tener encabezados claros y una estructura comprensible.

    Es preferible evitar tablas excesivamente complejas cuando la misma información pueda presentarse de una manera más sencilla.

    18.5. Documentos profesionales

    Antes de entregar un documento, revisa:

    • Ortografía y gramática.
    • Coherencia de títulos y estilos.
    • Numeración de páginas.
    • Índice actualizado.
    • Imágenes y leyendas.
    • Tablas completas.
    • Márgenes y saltos de página.
    • Ausencia de páginas vacías.
    • Formato de entrega correcto.
    • Privacidad y permisos de las imágenes.

    19. Práctica guiada: crear un informe técnico

    En esta práctica aprenderás a integrar las herramientas principales de Writer en un único documento.

    Situación profesional

    Trabajas como técnico en una empresa de soporte informático. Un cliente informa de que uno de sus ordenadores funciona lentamente y necesita un informe de la intervención.

    Debes elaborar un documento que pueda entregarse al responsable del departamento.

    Paso 1. Crear el documento

    Abre Writer y crea un documento nuevo.

    Guárdalo como:

    informe-incidencia-001.odt

    Paso 2. Introducir el contenido

    Utiliza la siguiente estructura:

    INFORME DE INCIDENCIA TÉCNICA

Datos de la intervención

Código: INC-001
Equipo: PC-ADMIN-01
Departamento: Administración
Fecha: [fecha de intervención]
Técnico: [nombre del técnico]

1. Descripción de la incidencia

El usuario informa de un rendimiento lento del equipo,
especialmente durante el inicio del sistema y la apertura
de varias aplicaciones.

2. Comprobaciones realizadas

Se comprueba el espacio disponible en el disco.
Se revisan las aplicaciones de inicio.
Se verifica el estado general del sistema.

3. Diagnóstico

Se identifica una carga elevada de aplicaciones
durante el inicio del sistema.

4. Solución aplicada

Se revisan las aplicaciones de inicio y se desactivan
las que no son necesarias, previa comprobación.

5. Pruebas finales

Se reinicia el equipo y se comprueba su funcionamiento.
Se verifica que las aplicaciones habituales se ejecutan
correctamente.

6. Conclusión

La intervención finaliza con resultado satisfactorio.
Se recomienda realizar mantenimiento periódico.

Estado final: Resuelta

    Los resultados descritos son un ejemplo didáctico. En una intervención real deben reflejarse únicamente las comprobaciones y acciones que se hayan realizado.

    Paso 3. Aplicar estilos

    Aplica los siguientes estilos:

    • Título principal: estilo de título.
    • Apartados numerados: Título 1 o el nivel adecuado.
    • Texto principal: estilo de cuerpo de texto.
    • Datos de identificación: tabla.

    Paso 4. Configurar la página

    Establece:

    • Papel A4.
    • Orientación vertical.
    • Márgenes uniformes.
    • Espaciado coherente.
    • Encabezado con el nombre de la empresa ficticia.
    • Pie con numeración automática.

    Paso 5. Insertar una tabla

    Crea una tabla con los datos de identificación:

    Campo Valor
    Código INC-001
    Equipo PC-ADMIN-01
    Departamento Administración
    Fecha Fecha de intervención
    Técnico Nombre del técnico

    Paso 6. Revisar el documento

    Comprueba que:

    • Los títulos tienen estilos coherentes.
    • Los párrafos no contienen saltos innecesarios.
    • La tabla es legible.
    • La numeración es automática.
    • No existen páginas vacías.
    • La ortografía es correcta.

    Paso 7. Exportar

    Guarda el archivo ODT y expórtalo a PDF con el nombre:

    informe-incidencia-001.pdf

    Abre el PDF y comprueba que su apariencia coincide con la del documento original.

    Resultado esperado

    Debes entregar dos archivos:

    • informe-incidencia-001.odt
    • informe-incidencia-001.pdf

    Elaboración de un manual de mantenimiento informático

    Requisitos mínimos

    El documento debe incluir:

    11. Encabezados y pies de página.

    • Las imágenes deben poder utilizarse legalmente.
    • El contenido debe estar estructurado con estilos.

    23. Resumen del tema

    Un procesador de textos permite crear y mantener documentos estructurados y profesionales. Para utilizarlo correctamente no basta con escribir y modificar el aspecto de las letras: también es necesario comprender cómo se organiza el contenido y cómo se distribuye en las páginas.

    Los conceptos fundamentales estudiados son:

    • La diferencia entre editores y procesadores de textos.
    • La interfaz y las herramientas básicas de Writer.
    • La creación, apertura y almacenamiento de documentos.
    • La edición y el formato de caracteres y párrafos.
    • El uso de estilos para estructurar documentos.
    • La creación de listas, tablas e imágenes.
    • La configuración de páginas, encabezados y pies.
    • La revisión ortográfica y la búsqueda de texto.
    • La utilización de plantillas e índices automáticos.
    • La compatibilidad entre formatos y la exportación a PDF.
    • La accesibilidad y las buenas prácticas documentales.

    Idea clave: un documento profesional debe ser claro, coherente, fácil de mantener y adecuado para su destinatario. Los estilos, las tablas y los campos automáticos no son únicamente herramientas de presentación: también ayudan a reducir errores y a trabajar de forma más eficiente.
